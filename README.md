# 반도체_3 | 단채널 효과(SCE) & 소자 물리 역순 질의응답 마스터 대시보드

반도체 소자 물리 및 단채널 효과(SCE)에 관한 심층 질의응답을 실제 질문자의 질문 순서 역순(최신순)으로 정렬하여 인터랙티브 웹 대시보드로 제공하는 공식 저장소입니다.

## 📌 주요 특징
1. **[💡 면접 대비 3~4줄 핵심 요약]**: 각 토픽 상단에 3~4줄 핵심 압축 요약 배치
2. **[📊 정밀 인라인 SVG 그래픽]**: 복잡한 물리 메커니즘을 텍스트가 아닌 선명한 인라인 SVG 다이어그램으로 시각화
3. **[📘 세부 마스터 강의 노트]**: 푸아송 방정식, 2D 전계 벡터 분포, 공핍층 역학, 실제 양산 공정 연계 등 깊이 있는 물리적 해석 제공
4. **[🔄 최신순 정렬 체계]**: 가장 최근 질문이 항상 01번 탭으로 등록되는 역순(최신순) 정렬 체계
